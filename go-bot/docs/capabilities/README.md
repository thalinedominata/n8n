# Capabilities

Catalog of Go-Bot's capabilities. The public-facing summary renders from
`src/data/capabilities.ts`.

Sees & understands · Listens naturally · Converses warmly · Moves gracefully ·
Solves problems · Learns you.

As capabilities mature, each gains a spec here: behavior contract, safety
constraints, and demo scenarios. Interactive capability demos are a V2
roadmap item.
