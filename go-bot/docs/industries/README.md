# Industries

Industry solution documentation. The public-facing summary renders from
`src/data/industries.ts`.

Current verticals: Healthcare · Education · Hospitality · Retail ·
Travel & Mobility · Industrial.

Each vertical will receive a solution brief (`healthcare.md`, `education.md`,
…) covering deployment model, integrations, and case studies as programs
launch. Adding a vertical = one entry in the data file + one brief here.
